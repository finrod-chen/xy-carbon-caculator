冷媒逸散：為什麼要填、怎麼填

一句話：冷媒漏出去的量，每公斤造成的暖化效果遠高於同等重量的二氧化碳，所以要逐次記錄補充量。

公司哪些設備有冷媒：超低溫冰箱、冰水主機、空調。（內容待與實驗室確認設備清單）

你需要準備

  • 維修／補充冷媒的服務單
  • 冷媒種類與補充公斤數

計算方式

補充量（kg）× 該冷媒的暖化潛勢值 = 排放量。暖化潛勢值來自 IPCC 報告 [R-13]。

資料狀態：此處引用的 [R-13] 目前核對狀態為「待核對」。
